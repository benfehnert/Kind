Kind data model

Conceptual schema from the Kind mobile prototype and marketing site · Generated for documentation

Overview

Kind connects individuals (explorers) who run structured N-of-1 health explorations with researchers who publish and collaborate on exploration protocols. Daily logs, social follow/nice/message interactions, and privacy-controlled citizen-science contribution form the core loop.

RoleResponsibility
IndividualEnroll in explorations, log daily, follow peers/researchers, manage consent
ResearcherLink to explorations, verified profile, followed by community
ExplorationCatalog protocol: phases, log fields, outcomes, participant counts

Prototype mapping

  • EXPLORATIONS → explorations + phases, fields, outcomes
  • COMM_USERS / BASIC_USERS → individuals
  • RESEARCHERS → researchers, researcher_explorations
  • followingSet → individual_follows
  • EXPLORATION_FOLLOWERS → view exploration_participants
